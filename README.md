# 진로전담교사 심층면접 36문항

239문항 구술형 자료를 **심층면접 형식**(제시문 + 하위질문 3개 + 구간별 모범답안)으로 재구성한 연습용 웹앱입니다.
문항 수는 줄었지만 한 문항당 분량과 밀도는 실제 심층면접 수준으로 끌어올렸습니다.

## 무엇이 달라졌는가

| | 기존 239문항 | 이 자료 36문항 |
|---|---|---|
| 형태 | 단문 질문 1개 + 핵심정리·대응방안 | 정책 제시문 + 하위질문 3개 |
| 답안 | 서술 문단 2개 | 도입·전개·마무리 구간, 구간별 권장 발화 시간 |
| 분량 | 문항당 400~600자 | 문항당 약 1,200자 / 평균 2분 8초 |
| 최신성 | 2025년 기준 | 2026년 8월 기준 정책 반영 (21문항) |

239문항은 주제가 크게 겹쳤습니다(예: 진로연계교육 관련 12문항, 커리어넷·플랫폼 관련 18문항).
이를 주제별로 묶어 **하나의 심층 문항 안에서 하위질문으로 분화**시키는 방식으로 압축했습니다.
각 문항 하단에 원본 대응 문항 번호를 표기해 두었으므로, 239문항 원본과 대조하며 확인할 수 있습니다.

## 문항 구성

- 총 36문항 (S등급 20 · A등급 16)
- 영역: 제도·직무 3, 교육과정 7, 상담 4, 검사·이론 4, AI·미래 6, 체험·플랫폼 4, 전남·협업 5, 지원동기·역량 3
- 31~36번은 앞서 작성한 신규 정책 대응 6문항입니다.

## 사이트 사용법

- 문항을 고르면 제시문과 하위질문 3개가 나옵니다. **키워드와 모범답안은 처음에 가려져 있습니다.**
- `⏱ 구상 시작` — 30초·1분·2분 중 선택. 실전은 2분 기준으로 연습하시길 권합니다.
- `🔊 문항 읽어주기` — 면접위원 목소리로 제시문과 하위질문을 낭독합니다.
- `🔊 모범답안 읽어주기` — 답변 목소리로 낭독하며, 읽는 구간이 막대와 함께 표시됩니다.
- 답안의 **구간을 누르면 그 지점부터** 읽습니다. 전개만 반복 연습할 때 유용합니다.
- 속도 0.8 ~ 2.0배. 완료 표시는 브라우저에 저장되어 다음 방문에도 유지됩니다.
- 키보드: `←` `→` 문항 이동, `Space` 문항 낭독, `Esc` 정지.

```
app.js

.nojekyll
README.md
```

`questions.json`은 다른 도구에서 쓸 수 있도록 함께 넣어 둔 같은 내용의 원본 데이터입니다.

## MP3 만들기

`qa_data.py`를 기존 `make_mp3.py`와 같은 폴더에 두고 실행하면 36문항 음원이 생성됩니다.
기존 6문항용 `qa_data.py`를 이 파일로 교체하시면 됩니다.

```powershell
python make_mp3.py --think 120        # 구상 2분 — 실전 모드
python make_mp3.py --answer-only      # 모범답안만 — 암기용
python make_mp3.py --rate +30%        # 빠르게 — 복습용
python make_mp3.py --only 6,17,20     # 특정 문항만
```
