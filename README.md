# 진로전담교사 심층면접 · 36문항

2027학년도 중등 진로전담교사 선발 **2차 전형(심층면접)** 대비 연습 도구입니다.
239문항 자료를 재구성한 48문항에서 **옥석을 가려 12문항을 덜어 낸 36문항**이며,
선발계획과 2차 전형 실시계획의 평가요소를 문항마다 연결했습니다.

## 48 → 36으로 덜어 낸 기준

빠진 12문항은 **행정·조직 실무형**(법적 근거와 역할 재정립, 연간계획과 성과환류, 상담 기록 관리,
교내 협력체계, 조직·공간·지역 연계, 체험처 발굴과 돌발상황)과 **개인 이력형**(전직 동기, 보직·연수 경력),
그리고 다른 문항에 흡수되는 주제(교과연계 진로교육, 학부모 진로교육, CAIT, 대입제도 개편)입니다.
남은 36문항은 2차 전형 평가 주안점 ②(진로진학 전문지식·상담이론 이해·상담능력)에 정면으로 걸립니다.

## 문항마다 붙인 것

| 항목 | 내용 |
|---|---|
| **면접위원이 확인하는 것** | 이 문항에서 평가되는 지점 2~3개 — 평가 주안점 ①②에 대응 |
| **여기서 갈립니다** | 상위권에서 점수가 갈리는 감점 지점 |
| **인용할 수 있는 근거** | 답변에서 쓸 법령·정책·통계 3~4개 (연도·출처 표기) |
| **평가 주안점 배지** | 진로교육 능력·자질 / 업무적합도 / 진로진학 전문지식 / 상담이론 이해 / 상담능력 |

## 이 자료의 기준

| 전형 조건 | 반영 방식 |
|---|---|
| 구상 포함 **문항당 3분 이내**, 초과분 채점 미반영 | 36문항 모두 답변 발화 **2분 22초**로 통일. 구상 40초를 더해 3분 |
| 답변 종료 **30초 전 타종 1회** | 실전 타이머가 같은 지점에서 신호음 |
| **관리번호 부여 · 신분 노출 금지** | 학교명·교과명·연구회·표창 등 특정 가능한 표현 전면 배제 |
| 면접실 2개, 각 **1문항씩 총 2문항** | 한 문항을 3분 안에 끝내는 단위로 구성 |
| 2차 결과 **60% 미만 과락**, 배점 50점 | 과락 회피가 아니라 상위권 득점을 목표로 밀도 조정 |

## 반영한 최신 정책 (2026. 8. 기준)

- 고교학점제 안착 지원 대책(2026.1.30.) — 선택과목 이수기준 완화, 창체 학년별 출석 기준, 미이수 학생 온라인 학점 취득 경로, 미도달과 미이수의 구분
- 국가교육위원회 2028~2037 국가교육발전계획 — 수능 절대평가·서논술형 확대 **검토 단계**, 10월 말 시안 공개, 내년 3월 확정
- 2026년 교육부 업무계획 — AI 보편교육, AI는 학습분석·진로상담을 지원하는 **보조 도구**로 규정, 수행평가 AI 활용 관리 방안
- 2026 전남교육 — 도약하는 글로컬 전남교육, AI 인재양성·AI 기반 2030교실, 공생교육
- 2025 초·중등 진로교육 현황조사 — 희망직업 보유 70.5%, 중학생 고교 진학 희망 91.1%, 고졸 후 대학 진학 희망 64.9%(3년 연속 감소), 진로심리검사 실시율 중 98.3%·고 98.9%

## 사용법

- 왼쪽에서 영역·등급으로 범위를 좁히고, 문항을 고르면 제시문과 하위질문 3개가 나옵니다. 키워드와 모범답안은 처음에 가려져 있습니다.
- `⏱ 3분 시작` — 실전 3분이 기본이며, 구상 40초 / 답변 2분 20초로 나누어 연습할 수도 있습니다.
- `🔊 읽어주기` — 0.8~2.0배속. 답안 구간을 누르면 그 지점부터 읽습니다.
- `⛶ 전체화면` — 우측 상단 버튼 또는 `F` 키. 키보드 `←` `→` 이동, `Space` 문항 낭독, `Esc` 정지.

## 배포

압축을 풀어 `index.html` `style.css` `app.js` `data.js` `.nojekyll` 을 저장소 최상단에 올리고 Settings → Pages에서 브랜치를 지정하십시오.
`questions.json`은 원본 데이터, `qa_data.py`는 기존 `make_mp3.py`에 넣어 쓰는 MP3용 파일입니다.
